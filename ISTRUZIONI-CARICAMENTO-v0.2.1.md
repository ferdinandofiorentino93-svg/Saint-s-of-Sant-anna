# Caricamento della preview 0.2.1 da smartphone

1. Scarica ed estrai `saints-santanna-v0.2.1-github-pages.zip` sul telefono.
2. Apri il repository GitHub `Saint-s-of-Sant-anna`.
3. Tocca **Add file → Upload files**.
4. Seleziona tutti i file con suffisso `v0.2.1` contenuti nella cartella estratta. Seleziona i file, non la cartella e non lo ZIP.
5. Caricali nella radice del repository, allo stesso livello dei file già presenti.
6. Premi **Commit changes**.
7. Attendi il completamento della pubblicazione GitHub Pages.
8. Apri la preview:

`https://ferdinandofiorentino93-svg.github.io/Saint-s-of-Sant-anna/index-v0.2.1.html`

## Importante

- Non eliminare `index.html`.
- Non rinominare `index-v0.2.1.html` in `index.html`.
- Non sovrascrivere i file della versione attuale.
- Questa è una pagina di prova separata. Solo dopo averla verificata si potrà decidere se renderla la pagina principale.
