# Caricamento dal telefono — v0.1.2

1. Estrai lo ZIP sul telefono.
2. Apri il repository GitHub `Saint-s-of-Sant-anna`.
3. Scegli **Add file → Upload files**.
4. Seleziona tutti i file che trovi dentro la cartella estratta (non lo ZIP e non la cartella esterna).
5. Assicurati che GitHub li carichi nella radice del repository, sullo stesso livello dei vecchi file.
6. Premi **Commit changes**.

**Non eliminare e non rinominare i vecchi file in questa fase.** Tutti i file nuovi hanno il suffisso `-v0.1.2`, quindi la versione esistente resta intatta.

Dopo il commit apri questo indirizzo per provare la nuova versione:

`https://ferdinandofiorentino93-svg.github.io/Saint-s-of-Sant-anna/index-v0.1.2.html`

Controlla la partita locale: apri le abilità del giocatore, prova quelle con il pulsante **Attiva**, risolvi uno Showdown e poi il tiro. Se questa pagina funziona, si potrà sostituire la pagina iniziale del sito con questa build.
