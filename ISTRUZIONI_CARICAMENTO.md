# Caricamento dal telefono

1. Estrai lo ZIP sul telefono.
2. Apri il repository GitHub e scegli **Add file → Upload files**.
3. Seleziona tutti i file dentro la cartella estratta (non selezionare la cartella esterna e non caricare lo ZIP).
4. I file devono finire nella radice del repository: `index.html`, `styles.css`, `app.js`, `catalog.js`, `catalog-data.js`, `engine.js`, `game-config.js`, `match.js`, `online.js`, `config.js`, `regolamento.html`, `ARCHIVIO_E_DISCREPANZE.md`, `README.md`, `.nojekyll`.
5. Esegui **Commit changes**.
6. Apri GitHub Pages e aggiorna il sito.

Se GitHub chiede di sostituire file già presenti con lo stesso nome, conferma: questa build deve aggiornare i file della precedente versione.
